1. What Is a Regression Line?

1.1 The Anatomy of a Line

Every simple linear regression model is just an equation for a straight line:

Y=β0+β1XY = \beta_0 + \beta_1 XY=β0​+β1​X

  • β0\beta_0β0​ (Intercept) — where the line crosses the Y-axis, i.e., the predicted value of YYY when X=0X = 0X=0.
  • β1\beta_1β1​ (Slope / Coefficient) — how much YYY changes for every 1-unit increase in XXX.
In [3]:
# A line to isolate the concept: y = 2 + 3x
x_toy = np.linspace(0, 4, 100)
b0, b1 = 2, 3
y_toy = b0 + b1 * x_toy

fig, ax = plt.subplots(figsize=(7, 6))
ax.plot(x_toy, y_toy, color="#0055A0", linewidth=2.5)

# Mark the intercept
ax.scatter([0], [b0], color="crimson", s=90, zorder=5)
ax.annotate(f"Intercept (β0 = {b0})\nValue of Y when X = 0",
            xy=(0, b0), xytext=(0.4, b0 - 2.5),
            arrowprops=dict(arrowstyle="->", color="crimson"), fontsize=10, color="crimson")

# Draw a rise/run triangle for the slope, starting at x=1
x_start, x_end = 1, 2
y_start, y_end = b0 + b1 * x_start, b0 + b1 * x_end
ax.plot([x_start, x_end], [y_start, y_start], color="darkgreen", linewidth=2)   # run
ax.plot([x_end, x_end], [y_start, y_end], color="darkgreen", linewidth=2)       # rise
ax.annotate("run = 1", xy=((x_start + x_end)/2, y_start - 0.6), color="darkgreen", fontsize=10, ha="center")
ax.annotate(f"rise = {b1}", xy=(x_end + 0.1, (y_start + y_end)/2), color="darkgreen", fontsize=10)
ax.annotate(f"Slope (β1 = {b1})\nFor every +1 in X, Y changes by {b1}",
            xy=(x_end, (y_start+y_end)/2), xytext=(2.3, 4),
            arrowprops=dict(arrowstyle="->", color="darkgreen"), fontsize=10, color="darkgreen")

ax.set_xlim(-0.3, 4.3)
ax.set_ylim(0, 16)
ax.set_xlabel("X")
ax.set_ylabel("Y")
ax.set_title("Anatomy of a Regression Line:  Y = β0 + β1·X")
plt.tight_layout()
plt.show()

Read the picture, not just the equation:

  • The red dot is the intercept. It marks where the line starts, at X=0X = 0X=0.
  • The green triangle shows the slope. We moved 1 unit right (run = 1) and the line went up 3 units (rise = 3)

1.4 Applying the Equation to Real Historical Data

The equation isn't abstract — it gets applied row by row to every car already in our dataset. For each car, only the predictor value changes; the intercept and slope stay exactly the same, because they describe the line itself, not any single car.

Predicted MPG⏟Y^  =  37.29⏟Intercept β0  +  (−5.34)⏟Slope β1×wt⏟Predictor X\underbrace{\text{Predicted MPG}}_{\hat{Y}} \;=\; \underbrace{37.29}_{\text{Intercept } \beta_0} \;+\; \underbrace{(-5.34)}_{\text{Slope } \beta_1} \times \underbrace{\text{wt}}_{\text{Predictor } X}Y^Predicted MPG​​=Intercept β0​37.29​​+Slope β1​(−5.34)​​×Predictor Xwt​​

Let's plug in 6 real cars from our historical data and watch the same equation play out differently for each one.

How to read every row the same way:

Column Role Changes from car to car?
Predictor X (wt) The input; this specific car's weight Yes, this is the only thing that differs between cars
Intercept β0 and Slope β1 The model itself, fixed once the line is fit No, same value for every car, every time
Slope × X The predictor's contribution to the prediction Yes, because X changes
Predicted Ŷ Intercept + (Slope × X); the model's answer Yes, this is the final output
Actual Outcome Y What really happened, from historical data Yes, this is ground truth, not something the model produced
Residual (Y − Ŷ) Actual minus Predicted; how far off the model was for that car Yes, this is what OLS was minimizing when it fit the line

Worked example, step by step, for the first row:

Mazda RX4 has weight (X) = 2.62. Plug it into the equation:

Y^=37.29+(−5.34)(2.62)=37.29−13.99=23.30\hat{Y} = 37.29 + (-5.34)(2.62) = 37.29 - 13.99 = 23.30Y^=37.29+(−5.34)(2.62)=37.29−13.99=23.30

The model predicts 23.30 mpg. The car's actual mpg was 21.0. The residual is 21.0−23.30=−2.3021.0 - 23.30 = -2.3021.0−23.30=−2.30, meaning the model overestimated this car's fuel efficiency by 2.30 mpg.

Key idea: the intercept and slope are properties of the line, fit once using all the historical data at the same time. They do not change from car to car. Only the predictor (X) and, as a result, the prediction (Ŷ), change.

2.1 The 3-Table Structure

Table What it contains
Table 1 (top) Overall model quality: R-squared, F-statistic, sample size, etc.
Table 2 (middle) The coefficient table — Intercept, slope, std err, t, p-value, CI.
Table 3 (bottom) Residual diagnostics: Omnibus, Durbin-Watson, Jarque-Bera, Cond. No., etc.

2.2 Numbers to focus on

At this stage of the course, you only need 6 values from the entire printout. Everything else is either a technical diagnostic (for later modules) or metadata that doesn't affect interpretation.

Value Where Why it matters right now
R-squared Table 1 The percent of variation in Y explained by X. Bigger means a better fit.
Adj. R-squared Table 1 The same idea as R-squared, adjusted for the number of predictors. In simple linear regression, with only one predictor, it stays very close to R-squared.
F-statistic and Prob (F-statistic) Table 1 Tests whether the model as a whole is statistically significant. If Prob(F-statistic) is less than 0.05, the model is meaningful.
coef Table 2 Builds your regression equation, the intercept and slope.
P>|t| Table 2 Tests whether each individual predictor is statistically significant.
[0.025, 0.975] Table 2 The 95% confidence interval for each coefficient.

2.3 Visualizing What R-squared Actually Means

R-squared is often memorized as "percent of variance explained" without students seeing what that variance is. Let's make it visible.

In [10]:
y = fleet_data["mpg"]
y_mean = y.mean()
y_pred = lm_fleet.fittedvalues

fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# --- Left: Total variance = distance of each point from the MEAN (no model at all) ---
axes[0].scatter(fleet_data["wt"], y, color="#438BC4", s=50, zorder=3)
axes[0].axhline(y_mean, color="gray", linestyle="--", linewidth=2, label=f"Mean mpg = {y_mean:.1f}")
for xi, yi in zip(fleet_data["wt"], y):
    axes[0].plot([xi, xi], [y_mean, yi], color="crimson", alpha=0.5, linewidth=1)
axes[0].set_title("Without a Model:\nTotal Variation Around the Mean")
axes[0].set_xlabel("Vehicle Weight"); axes[0].set_ylabel("MPG")
axes[0].legend()

# --- Right: Remaining variance = distance of each point from the REGRESSION LINE ---
axes[1].scatter(fleet_data["wt"], y, color="#438BC4", s=50, zorder=3)
x_line = np.linspace(fleet_data["wt"].min(), fleet_data["wt"].max(), 100)
axes[1].plot(x_line, b0_fleet + b1_fleet * x_line, color="#0055A0", linewidth=2.5, label="Regression line")
for xi, yi, ypi in zip(fleet_data["wt"], y, y_pred):
    axes[1].plot([xi, xi], [ypi, yi], color="crimson", alpha=0.5, linewidth=1)
axes[1].set_title("With the Model:\nLeftover Variation Around the Line")
axes[1].set_xlabel("Vehicle Weight"); axes[1].set_ylabel("MPG")
axes[1].legend()

plt.tight_layout()
plt.show()

print(f"R-squared = {r2:.3f}  →  the model explains about {r2*100:.0f}% of why MPG varies from car to car.")
print("The red lines on the RIGHT are much shorter than on the LEFT — that shrinkage IS R-squared.")
R-squared = 0.753  →  the model explains about 75% of why MPG varies from car to car.
The red lines on the RIGHT are much shorter than on the LEFT — that shrinkage IS R-squared.

Discussion:

R-squared measures how much shorter the red error lines get once you add the regression line, compared to just guessing the average every time.

  • Left panel: with no model, our best guess for any car's MPG is just the average MPG. The red lines show how wrong that guess is.
  • Right panel: once we use weight to predict MPG, the red lines (errors) shrink a lot. This shrinkage gives us an R-squared of 0.753, meaning that a vehicle's weight explains 75.3% of the variance in its MPG.

Discussion:

  • P-value (P>|t| = 0.000): Proves the relationship is statistically significant. Because it is well below the 0.05 threshold, it confirms that weight genuinely affects MPG and isn't just a random coincidence.

  • 95% Confidence Interval ([0.025 to 0.975]): Provides a realistic range for our prediction. While the exact estimate is a 5.34 MPG drop, we are 95% confident the true drop is somewhere between 4.20 and 6.49 MPG for every unit of weight added.

3. Writing a Complete Interpretation

Now that you can read R-squared, the F-test, and the coefficient table, you can write a full interpretation instead of only describing the slope.

Template:

*"The model explains {r_squared}% of the variation in {outcome}. The overall model is {overall_significance} (F = {f_stat}, p = {f_pvalue}). As {predictor} increases by 1, {outcome} {direction} by {coefficient} (p = {p_value}), which is {coef_significance}."*

Filled in for wt → mpg:

"The model explains 75% of the variation in MPG. The overall model is statistically significant (F = 91.4, p < 0.001). As weight (wt) increases by 1 (1000 lbs), MPG decreases by 5.34 (p < 0.001), which is significant."
